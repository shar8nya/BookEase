# BookEase 🎟️

BookEase is a modern event discovery and ticket booking platform designed to make finding events and booking tickets simple, interactive, and user-friendly.

The platform brings event discovery, seat selection, booking review, confirmation, and digital tickets together in one seamless experience.

---

## ✨ Features

### 🎭 Event Discovery

- Browse available events
- View event details
- Explore different event categories
- View event posters and information

### 🎟️ Seat Selection

- Interactive seat selection
- Available, selected, booked, and VIP seat states
- Seat-based pricing
- Multiple seat selection
- Real-time booking summary

### 📋 Booking & Ticketing

- Review selected seats before confirmation
- Price breakdown
- Booking confirmation
- Digital ticket generation
- Booking ID generation
- Event and seat information displayed on tickets

### 👤 User Features

- User registration and login
- View bookings
- Access booking history

### 🛠️ Admin Features

- Admin login
- Add events
- Manage events
- Admin dashboard

### 🌓 UI

- Light and dark mode
- Responsive interface
- Modern event-booking inspired design

---

## 🔄 Booking Flow

Browse Events

The booking and ticketing module includes:

- Booking confirmation
- Digital ticket generation
- Booking ID
- Event poster integration

## 🚀 Getting Started

### 1. Clone the Repository

git clone https://github.com/shar8nya/BookEase.git

Open the project folder in VS Code or your preferred code editor.
